# Ideas Parking Lot

- **"Follow the money" view** — collapse the river and show only the funding graph for a topic.
- **Evidence vs belief gap meter** — highlight topics where public opinion and evidence diverge most.
- **Later-confirmed hall of fame** — claims that were fringe and turned out true (and the reverse).
- **AI drift tracker** — chart how different models' answers to the same claim change by version.
- **Steelman challenge** — reward users for writing the best version of a view they disagree with.
- **Falsifiability field** — every theory must state what evidence would prove it wrong.
- **Edit wars as artefacts** — turn heavy edit history into its own explorable node.
- **Trail sharing** — "my rabbit hole from penicillin to Big Pharma fines" as a shareable flythrough.
- **Imported votes** — users link poll results from other platforms; shown with method and source.
- **Classroom mode** — guided tours through a topic for schools.
- **Time-machine view** — see the whole map "as of" any date, including what was believed then.
- **VR/AR mode** — walk the river.
- **Funding disclosure badges** for editors.
- **Penalty alerts** — when a new fine lands against an entity, every source tied to it updates live.
