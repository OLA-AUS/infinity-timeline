# Governance & Anti-Capture

The project must never become ideology-driven or corporate-funded rubbish. Structure, not promises, prevents that.

## Money
- Nonprofit / foundation structure.
- **Per-donor cap** (e.g. no single donor > 5% of annual income).
- **Every donation is a FundingEdge on the timeline**, publicly clickable like any other funder.
- No advertising. No selling user data.

## Code & data
- Open-source licence (AGPL suggested so hosted forks stay open).
- Nightly public data dumps — if the platform is ever captured, anyone can fork it.

## Moderation
- Every moderation action is a public log entry: what, who, why, rule cited.
- Appeals are public.
- Moderators disclose conflicts of interest like any editor.

## Free expression, with a few hard lines
Any claim can be posted, including fringe theories. They get the full treatment (steelman, evidence, counter-evidence, falsifiability). Very few things are not decided by votes:
1. Claims about **living private individuals** need a higher sourcing bar (defamation).
2. No harassment, doxxing or threats.
3. **Dangerous health/safety claims** stay visible but carry a clear evidence summary up front.
4. Illegal content is removed (logged publicly where lawful).

## Changing the rules
Trust-model weights, status thresholds and these rules are versioned. Changes need a public proposal, comment period and a vote by established contributors. The history of rule changes is itself on the timeline.

## Editors
- Pseudonyms allowed; reputation is earned per field.
- Editors can optionally verify identity and **must disclose** relevant conflicts (employer, funding) to edit topics where they have them.
